Porto, Portugal · Oct 2024 – Feb 2025

Development of a semi-automatic platform for calcium scoring in cardiac computed tomography. The platform allowed clinicians to annotate possible calcification areas to validate and improve neural network performance for automatic detection Platform was developed using PyQt to read dicom files and save segmentation masks to NRRD format.The codebase was packaged into a standalone executable using PyInstaller to allow clinicians to easily run and use the application without requiring a local Python environment.
